# Red Black Tree

## Why?
- Was reading [Operating Systems: Three Easy Pieces](https://pages.cs.wisc.edu/~remzi/OSTEP/) found scheduling interesting so decided to build Red Black Tree.

## How to run?
- Requires `gcc` and `make`(otherwise you can run the commands directly after looking into makefile) tested on linux Fedora
- Run `make` command, you will get a `rbt` binary which you can run to see the RBT visualization
